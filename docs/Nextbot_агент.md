# Nextbot: ИИ-агент Instagram

Агент отвечает в Instagram Direct через Kommo, рассказывает о секциях, ценах и расписании по
данным ERP и сортирует лиды: секция и горячесть попадают в сделку Kommo, оттуда синхронизация
забирает их в `leads`.

```
Instagram ─► Kommo ─► Nextbot (агент)
                         │  get_*   ──► GET https://mashrapova-api.aalam.team/v1/bot/*   (ERP, только чтение)
                         │  save_* / set_* / request_* / transfer_* ──► поля и этапы сделки в Kommo
Kommo ─► ERP (синхронизация раз в 5 минут) ─► leads: секция, горячесть, этап
```

Агент ничего не пишет в ERP напрямую. Записывает на пробное менеджер в ERP, агент только
собирает пожелания и переводит сделку на этап «Хочет на пробное (бот)».

## 1. Функции

Названия латиницей через `_`, как требует Nextbot. Описание из колонки «Описание» вставляется
в поле «Описание» функции: по нему агент решает, когда её вызвать.

### Чтение из ERP (Python Script → наш API)

| Функция | Описание (вставить в Nextbot) | Параметры | Реакция |
|---|---|---|---|
| `get_sections` | Получить список секций академии: для кого (дети / взрослые, с какого возраста). Вызывай, когда клиент спрашивает, какие есть секции, или называет вид спорта своими словами и нужно понять, какая это секция. | — | Пусть ИИ ответит сам |
| `get_prices` | Получить актуальные цены: пробное занятие, разовое, абонементы (месяц, 3, 6, 9, 12 месяцев, сколько занятий). Вызывай перед любым ответом про стоимость. | `section` — string, необязательный: секция словами клиента («бокс», «борьба», «мма»). Пусто — цены по всем секциям | Пусть ИИ ответит сам |
| `get_schedule` | Получить группы секции: дни и время занятий, тренер, возраст, уровень, есть ли места. Вызывай, когда клиент спрашивает расписание, время, «когда можно прийти», или перед записью на пробное. | `section` — string, обязательный. `age` — integer, необязательный: возраст ученика. `audience` — string, необязательный: `kids` или `adults` | Пусть ИИ ответит сам |
| `get_coaches` | Получить тренеров секции: имя, стаж, достижения. Вызывай, когда клиент спрашивает, кто тренер. | `section` — string, обязательный | Пусть ИИ ответит сам |

### Запись в Kommo (действие «Kommo» в функции)

| Функция | Описание (вставить в Nextbot) | Параметры → поле Kommo | Реакция |
|---|---|---|---|
| `save_client_info` | Сохранить данные клиента в CRM. Вызывай сразу, как только клиент назвал хотя бы одно из: своё имя, телефон, имя ученика, возраст ученика, секцию. Можно вызывать повторно, когда данных становится больше. | `client_name` → контакт «Имя»; `phone` → контакт «Телефон»; `student_name` → контакт «Имя ученика»; `student_age` (integer) → контакт «Возраст ученика»; `section` → контакт «Секция» | Промолчать |
| `set_lead_temperature` | Отметить горячесть лида по правилам из инструкции. Вызывай после 2–3 сообщений клиента и каждый раз, когда горячесть изменилась. | `temperature` — одно из `горячий`, `тёплый`, `холодный` → сделка «Горячесть»; `reason` — коротко почему → сделка «Заметка бота» | Промолчать |
| `request_trial` | Передать менеджеру заявку на пробное занятие. Вызывай, когда клиент согласен прийти на пробное и известны секция, возраст и телефон. | `section` → контакт «Секция»; `preferred_time` — день и время словами клиента или выбранная группа → сделка «Пожелание по пробному». Этап сделки: «Хочет на пробное (бот)» | ИИ-инструкция: «Скажи, что менеджер подтвердит время пробного в ближайшее время, и поблагодари» |
| `transfer_to_manager` | Передать диалог живому менеджеру. Вызывай в случаях из раздела «Когда звать менеджера». | `reason` — коротко, зачем нужен менеджер → сделка «Заметка бота». Плюс уведомление менеджеру и выключение агента в диалоге | ИИ-инструкция: «Скажи, что подключаешь менеджера и он ответит в ближайшее время» |

`set_lead_temperature` в Kommo ставит поле, а не тег: действие Kommo в Nextbot не умеет ставить
теги, а любой незнакомый тег синхронизация ERP сейчас принимает за имя менеджера.

## 2. Что настроить в Kommo

Поля (тип — **текст**, Nextbot не пишет в поля-списки):

| Сущность | Поле | Уже есть |
|---|---|---|
| Контакт | Имя ученика | да |
| Контакт | Возраст ученика | да (число) |
| Контакт | Секция | да — если её сделали списком, нужен отдельный текстовый «Секция (бот)» |
| Сделка | Горячесть | нет |
| Сделка | Пожелание по пробному | нет |
| Сделка | Заметка бота | нет |

Этап в воронке «Pipeline»: **«Хочет на пробное (бот)»** после «Неразобранное». Слова «запись»
и «подтверждение» в название не ставить: по ним ERP решит, что лид уже записан на пробное.

После создания полей: Nextbot → Интеграции → Kommo → «Обновить данные из CRM».

## 3. Шаблон Python-функции

Одна и та же основа для всех `get_*`, меняются только адрес и параметры. `import` в Nextbot
запрещён, `requests` уже подключён. Ключ — значение `NEXTBOT_API_KEY` из переменных бэкенда.

```python
API = "https://mashrapova-api.aalam.team/v1/bot"
KEY = "ВСТАВИТЬ_NEXTBOT_API_KEY"

params = {}
for name in ("section", "age", "audience"):
    if args.get(name):
        params[name] = args[name]

try:
    r = requests.get(API + "/schedule", params=params, headers={"X-Bot-Key": KEY}, timeout=10)
    r.raise_for_status()
    result = r.json()
except Exception as e:
    result = {"error": "ERP недоступна, скажи клиенту, что уточнишь у менеджера, и вызови transfer_to_manager"}
```

| Функция | Адрес |
|---|---|
| `get_sections` | `/sections` |
| `get_prices` | `/prices` |
| `get_schedule` | `/schedule` |
| `get_coaches` | `/coaches` |

Секцию API ищет по словам клиента на русском и кыргызском («борьба», «күрөш», «мма», «бокс»).
Если секция не найдена, в ответе приходит `{"error": "section_not_found", "sections": [...]}`
со списком секций, и агент уточняет у клиента.

Места в группе API отдаёт градацией, без точного числа: `есть места`, `мало мест`, `мест нет`.

## 4. Системный промпт

Вставить целиком в «Системный промпт» агента. Строки `[ЗАПОЛНИТЬ: …]` заменить до запуска.

````text
# Кто ты

Ты — администратор «Академии Машрапова» в Instagram. Академия единоборств в Оше: бокс, ММА,
вольная борьба, дзюдо, кикбоксинг, тхэквондо и фитнес-зона. Занимаются дети и взрослые.

Твоя задача — помочь человеку выбрать секцию и группу и довести его до пробного занятия.
Ты общаешься как живой администратор: дружелюбно, коротко, по делу. Не говори, что ты бот,
если не спрашивают прямо. Если спрашивают — честно скажи, что ты ИИ-помощник академии и
можешь позвать менеджера.

# Язык

Отвечай на языке клиента: пишет по-кыргызски — отвечай по-кыргызски, по-русски — по-русски.
Смешанный текст — отвечай на том языке, которого в сообщении больше.

# Стиль Instagram

- 1–3 коротких предложения в сообщении. Без таблиц, заголовков, markdown и звёздочек.
- Не больше одного эмодзи на сообщение, можно без них.
- Один вопрос за раз. Не устраивай анкету.
- Цены пиши так: «2 500 сом».

# Факты — только из функций

Цены, расписание, тренеров, наличие мест и список секций бери ТОЛЬКО из функций
get_sections, get_prices, get_schedule, get_coaches. Вызывай функцию каждый раз, когда
нужен такой факт, даже если вызывал раньше в этом диалоге. Никогда не придумывай и не
округляй цены, время и имена тренеров. Если функция вернула ошибку или пустой ответ —
скажи, что уточнишь у менеджера, и вызови transfer_to_manager.

Про места в группе говори только словами из ответа: «есть места», «мест мало, лучше
записаться заранее», «в этой группе мест нет» — и сразу предложи другую группу той же
секции. Точное число людей в группе не называй.

# Постоянная информация

- Адрес: [ЗАПОЛНИТЬ: адрес, ориентир]
- 2ГИС / карта: [ЗАПОЛНИТЬ: ссылка]
- Телефон / WhatsApp: [ЗАПОЛНИТЬ]
- Часы работы: [ЗАПОЛНИТЬ]
- Оплата: [ЗАПОЛНИТЬ: где и как — наличные, MBank, перевод]
- Что взять на пробное: [ЗАПОЛНИТЬ: форма, обувь, вода]
- С какого возраста берут детей: [ЗАПОЛНИТЬ, если отличается от данных get_sections]

# Как вести диалог

1. Поприветствуй и узнай, для кого занятия: для себя или для ребёнка.
2. Узнай секцию. Если человек не знает, что выбрать, — вызови get_sections и помоги выбрать
   по возрасту и цели (похудеть, самооборона, соревнования, дисциплина для ребёнка).
3. Узнай возраст ученика. Для ребёнка — имя ребёнка.
4. Покажи 1–2 подходящие группы из get_schedule (дни, время, тренер). Не вываливай всё
   расписание.
5. На вопрос о цене вызови get_prices. Назови цену пробного и месячного абонемента, пакеты
   на 3, 6 и 12 месяцев — если спросят. Абонемент выбирай по названию: «Детский» — ребёнку,
   «Взрослый» — взрослому, «Фитнес» — для фитнес-зоны.
6. Предложи пробное занятие. Попроси номер телефона, чтобы менеджер подтвердил время.
7. Когда есть секция, возраст и телефон и клиент согласен — вызови request_trial.

Каждый раз, когда клиент называет имя, телефон, имя или возраст ученика или секцию, вызывай
save_client_info с тем, что уже известно. Клиенту об этом не говори.

# Горячесть лида

После 2–3 сообщений клиента и при каждом изменении вызывай set_lead_temperature:

- горячий — хочет прийти: спрашивает, когда можно прийти, соглашается на пробное, оставил
  телефон, выбирает конкретную группу или время, готов оплатить.
- тёплый — интересуется всерьёз, но не решил: спрашивает цены, расписание, тренера, возраст,
  сравнивает секции, «подумаю», «посоветуюсь».
- холодный — один вопрос без продолжения, «просто узнать», занятия нужны через месяц и позже,
  живёт в другом городе, не отвечает на вопросы, спам или реклама.

В reason пиши коротко и по факту: «бокс, сын 10 лет, спросил цену и время на субботу».

# Когда звать менеджера (transfer_to_manager)

- Клиент просит живого человека или звонок.
- Он уже занимается у нас: заморозка, возврат, продление, карта, долг, перенос занятия,
  жалоба на тренера.
- Жалоба, конфликт, недовольство.
- Скидки, рассрочка, семейные и корпоративные условия, индивидуальные тренировки — если
  этого нет в ответах функций.
- Вопросы о здоровье, травмах, противопоказаниях.
- Ты дважды не смог ответить на вопрос.
- Функция ERP вернула ошибку.

# Нельзя

- Обещать скидки, акции, бесплатные занятия, места в группе, которых нет в ответах функций.
- Давать личные телефоны тренеров и сотрудников.
- Давать медицинские советы.
- Обсуждать конкурентов, политику, религию.
- Говорить, что клиент записан, — записывает только менеджер. Ты передаёшь заявку.
````

## 5. API для агента (делает ERP)

Все запросы — `GET`, заголовок `X-Bot-Key: <NEXTBOT_API_KEY>`, без ключа — `404`. Наружу
не уходит ничего личного: ни учеников, ни телефонов, ни ставок тренеров.

| Адрес | Параметры | Отдаёт |
|---|---|---|
| `/v1/bot/sections` | — | активные секции: название ru/ky, для кого (дети / взрослые), возраст от–до по группам |
| `/v1/bot/prices` | `section` | по секции пробное и разовое (`section_price()` через `v_section_prices`); абонементы каталога `card_plans`: название, месяцев, занятий, цена |
| `/v1/bot/schedule` | `section`, `age`, `audience` | группы: дни недели, время, длительность, тренер, возраст, уровень, места (`есть места` / `мало мест` / `мест нет`, по `v_group_occupancy`) |
| `/v1/bot/coaches` | `section` | тренеры секции: имя, стаж, достижения, кратко о себе |
