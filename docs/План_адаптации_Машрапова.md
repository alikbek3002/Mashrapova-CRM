## Этап 2 — бизнес-правила (следующий)

1. **Скидки (§3.3).** «Приведи друга» −300 сом с абонемента того, кто привёл; индивидуальная скидка
   с обязательной причиной. Сейчас есть только автоскидка 2-го ребёнка и процент без причины.
2. **Заморозка тренером (§4.3).** В Uniqum её отключили по решению клиента, Машрапову она нужна:
   вернуть в `freezes.ts` и приложение тренера, добавить уведомление менеджеру.
3. **Зарплаты (§10.1).** Сейчас тренеру начисляется фиксированная ставка за ребёнка (`groups.coach_rate_per_child`).
   Нужно: 40% выручки за занятие × число пришедших; тип оплаты «фикс» для дежурного тренера фитнес-зоны;
   персональные тренировки — 50%; занятие, отменённое по вине тренера, не оплачивается; аванс 20-го — 50% начисленного.
4. **Отмена по вине тренера (§5.3).** Флаг причины у отменённого занятия, который исключает занятие из зарплаты.
5. **Витрина «Выгодные абонементы»** (пожелание Академии, не из ТЗ). В разделе «Абонементы» блок
   анимированных карточек тарифов (красный / чёрный / бордовый, цены в сомах). Всё берётся из таблицы
   тарифов и редактируется там же: название, цена, описание.
6. **Матрица прав (§2.2).** Сверить `rbac.ts` и RLS. Добавить 2FA для директора и управляющего (§12.3).

## Этап 3 — продажи и коммуникации

- Воронка лидов (§8): этапы «новый → квалификация → запись на пробную → напоминание → не пришёл → конверсия»,
  SLA 10 минут на первый контакт и эскалация через 30 минут.
- KPI менеджеров (§7.4), дашборд директора (§11.1), отчёты (§11.2–11.4).
- Уведомления (§9): SMS.kg и WhatsApp, триггеры за 7 и 3 дня до окончания абонемента, в день окончания,
  win-back через 3 дня после, риск оттока при отсутствии 10+ дней.
