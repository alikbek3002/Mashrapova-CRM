# Академия Машрапова — ERP

ERP для зала единоборств «Академия Машрапова» (Ош): бокс, ММА, вольная борьба, дзюдо, кикбоксинг, таэквондо и фитнес-зона. Три роли: администрация (десктоп), тренер (PWA), родитель (PWA). Языки: RU / КЫ.

Движок взят из Uniqum Sport ERP. ТЗ — [docs/ТЗ_Академия_Машрапова.md](docs/ТЗ_Академия_Машрапова.md), план адаптации — [docs/План_адаптации_Машрапова.md](docs/План_адаптации_Машрапова.md).

## Структура

- `frontend/` — React + TypeScript (Vite). Дашборды админа, тренера и родителя.
- `Back/` — пусто. Сюда позже приедет бэкенд.

## Запуск фронта

```bash
cd frontend
npm install
npm run dev
```

Откроется http://localhost:5173. Сверху переключатели роли (админ / тренер / родитель), языка (RU / КЫ), и кнопка-шестерёнка — панель твиков стиля карточек.

## Сборка

```bash
cd frontend
npm run build
```
