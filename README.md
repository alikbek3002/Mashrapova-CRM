# Академия Машрапова — ERP

ERP для зала единоборств «Академия Машрапова» (Ош): бокс, ММА, вольная борьба, дзюдо, кикбоксинг,
таэквондо и фитнес-зона. ~525 активных клиентов, ~200 новых лидов в месяц, ~15 тренеров.

Три роли в одном приложении: администрация (десктоп), тренер (PWA), родитель (PWA).
Языки — русский и кыргызский.

Упор системы — **воронка лидов и удержание клиентов**: дожим лида по нормативу 10 минут, конверсия
пробной в покупку, контроль срока абонемента и win-back. Пропускной системы, турникетов и Face ID в
продукте нет — эти функции движка удалены.

## Структура

- `frontend/` — React 18 + TypeScript (Vite). Админка, приложение тренера, приложение родителя.
- `backend/` — Fastify + TypeScript. Деньги, зарплаты, заморозки, рассылки, файлы.
- `supabase/` — миграции, seed и стенд для их прогона.

## Запуск

```bash
# фронт
cd frontend && npm install && npm run dev      # http://localhost:5173

# бэк (нужен backend/.env, образец — backend/.env.example)
cd backend && npm install && npm run dev       # http://localhost:3001
```

## Граф знаний проекта (graphify)

Весь репозиторий — код, миграции и документы ТЗ — разобран в граф знаний: узлы-концепции, связи
`calls` / `imports` / `references` и сообщества-подсистемы. Нужен, чтобы находить ответ запросом к
графу, а не чтением файлов подряд.

```bash
# установка (один раз): SQL-грамматика обязательна — вся бизнес-логика живёт в миграциях
uv tool install "graphifyy[postgres,mcp,watch,leiden]"

# сборка графа
graphify extract . --code-only          # только код и SQL: локально, без LLM, ~15 секунд
graphify extract . --backend claude-cli # плюс документы ТЗ: семантический разбор через Claude Code

# работа с графом
graphify query "как считается зарплата тренера"
graphify path "refresh_card_notices" "notifications"
graphify explain "manager_kpi"
graphify god-nodes --top 15             # самые связанные узлы: через что всё проходит
graphify affected "v_payroll_attendance" # что сломается, если это изменить

graphify update .                        # после правок кода (AST, без LLM)
graphify label . --backend=claude-cli     # освежить названия сообществ после крупных изменений
```

Две особенности именно этого репозитория:

- **Спрашивать именами символов, а не по-русски.** Узлы подписаны идентификаторами кода, поэтому
  `graphify query "compute_coach_payroll v_payroll_attendance"` попадает в цель, а
  «как считается зарплата тренера» стартует с посторонних миграций.
- **У SQL связи называются `reads_from`, а не `calls`.** Для view и функций:
  `graphify affected "v_payroll_attendance" --relation reads_from` — набор отношений по умолчанию
  рассчитан на TypeScript и для SQL вернёт пусто.

`graphify-out/` в репозиторий не коммитится — пересобирается за ~15 секунд.
Что не индексируется, задано в [.graphifyignore](.graphifyignore).
Правила для Claude Code — в [CLAUDE.md](CLAUDE.md), хуки — в `.claude/settings.json`.

## Миграции и проверка расчётов

```bash
cd supabase/test
npm run migrate   # прогнать все миграции на настоящем Postgres, без Docker
npm run smoke     # проверить расчёты ТЗ: зарплата, возврат, квота заморозок, уведомления
npm run tariffs   # доля занятия и зарплата тренера по каждому тарифу
```
